# Pat's Skin Changer

## What is Pat's Skin Changer?

Skin Changer is a Minecraft mod for easily changing your current appearance.

It lets you change your skin, player model (wide/slim), cape and elytra textures. It is important to note that these changes are completely client-sided, meaning only you will be seeing the changes you make. It only changes your skin, cape and elytra texture, and has no effect on other player's appearances.

## How to use Pat's Skin Changer?

The usage is very simple.
1. Take the mod's jar file, put it in the `mods` folder in `.minecraft`. If the folder doesn't exist, make it yourself.
2. Make sure you use a Fabric instance to play the game. Download Fabric loader from https://fabricmc.net/ and install the version you want to use. (Mod only works with 26.2 for now)
3. Start the game.
4. Join to a world or a server.
5. Press 'V'. If it doesn't work, check `Controls -> Key Binds` in settings to see which button it is.
6. A menu will pop up, and now you can see the skins, capes and elytras you have put in previously. It will be only `Default`s if you didn't add any before.
7. Drag and drop the png you want to the correct box. For example a skin png to the skin box. It won't break anything if you drop it in a wrong box, but a skin's png won't look good on a cape.
- Quick note on elytra textures, they are pulled from capes' pngs. So if you want to use cape A's elytra with cape B, you need to drag cape A's png into the elytra box to use it.
8. Click on the files you want to use, there is a small preview on left to the each file's name.
9. Press `Escape` to leave the menu and you are all set.

## Why use Pat's Skin Changer?

You might be wondering why would anyone use a mod like this. Since Minecraft already let's you change your skin really easily it might seem pointless. So here are some usage cases I can think of,

1. You want to use a custom cape for free. This mod lets you do just that, you can put in any cape's png you want and you will see it on your back.
2. You don't like the texture of your elytra. You can change your elytra's texture with this mod, and it won't affect your existing cape at all.
3. You want to change between skins without leaving the game. Due to how this mod was made, you can change your skin in game without any lag or waiting. _Note that it is only a client-side change_
4. You have a skin you really want to use, but you don't want internet (NameMC) to archive it. Since this mod is client-side, you can use whatever skin you want and nobody else will know.
5. You don't have an original copy of the game, and the launcher you are using doesn't let you change your skin.
6. You want to test out skin in game to test it before wearing it.
7. You want to use an HD skin or cape. This mod supports usage of HD skins and capes with no issues.

These are the possible reasons I managed to come up with.

## Releavent Information
- .png files are saved in `.minecraft/custom-skins`, `.minecraft/custom-capes` and `.minecraft/custom-elytras`. `.minecraft` being wherever the instance of your game is.
- You can actually use any .png for all of these, they won't fit well or at all if they aren't formatted correctly. But you won't get an error.
- The mod is only client-side, because that is very easy to make. Maybe I will make a plugin or a mod to make it server-side as well. Though that will bring moderation issues with it.
- If you choose to use Custom Cape's Elytra but your cape actually doesn't have an elytra texture, your elytra will be invisible.

## Irrelevant Information
- I vibe coded this mod entirely, using Google Gemini 3.1 Pro. Most of the contribution I made were fixing mapping errors it made and copying redundant methods accross different similar classes.
- I made this mod pretty much to use it myself. I only realized there were many similar mods after I was done with it mostly. Before that I tried two terrible mods that didn't even work, hence why I decided to make this.
- It was fun and annoying to make. Annoying because I knew basically nothing about Minecraft's structure and Gemini decided to constantly get mappings wrong.
- If I am being honest, the only upside this mod has compared to other ones seems to be cape and elytra support, along with HD texture support. And I didn't even do anything to add HD texture support, it was already working when I added skin changing feature.
